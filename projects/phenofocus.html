Drug discovery · Cell images · 2026

PhenoFocus

Same biology, different skeleton

AI-driven drug discovery from cell images — advanced to the main round of the 2026 Research-Idea Commercialization Challenge.

Main round · 2026 Research-Idea Commercialization ChallengeOngoingTeam Lead · 4-member team2026 – ongoing

1Topic

Drug programs stall when every promising compound shares one chemical skeleton — a single toxicity or patent problem stops them all.

2What I did

As team lead, built a search layer on a model that links chemical structure to how compounds change cell images, and tested whether it finds same-mechanism compounds with different skeletons.

3Result

From one HDAC-inhibitor hit, both other HDAC inhibitors in a 31-compound library landed in the top 5 — one from a different chemical class.

VisionWhy it matters to me

What a drug does to a cell is a rule of nature we can photograph. If a model learns it, it can suggest molecules a chemist would not have tried. Next, I want to test the image side across different cell lines — the step that makes this useful in a real lab.

— Jiheon Kang

01 · BackgroundThe question

Cell Painting photographs stained cells, so every compound leaves a visual fingerprint of what it does. A model that has learned which compounds make cells look alike can be asked for compounds that act the same way but look different chemically — scaffold hopping in software instead of at the bench.

02 · ApproachHow it works

  1. Start from one hitFeed in a single compound that is known to work in cells.
  2. Search in biology spaceRank a compound library by how similarly the model expects each one to change cells.
  3. Keep the new skeletonsCheck chemical similarity so that candidates are truly different molecules.
  4. Be honest about scopeBenchmark across six mechanisms and write down where it fails.

03 · ResultsWhat we found

0.97

AUROC for finding same-mechanism compounds

one query · 31-compound library

6.2×

enrichment of same-mechanism hits in the top 5

chemical look-alike search: 3.1×

0.10

chemical similarity of the rank-4 hit to the query

an HDAC inhibitor from a different chemical class

Exploratory: a single query on a small library. Across six mechanisms the average was lower (macro AUROC 0.716), so this is a promising start, not a proof.
